- Tested and verified on Odoo 17.0 and 18.0

## Installation

1. Download the module and extract it so that the folder `odoo_allinoneaccessibilitypro` is placed inside one of your Odoo **addons paths** (for example `/opt/odoo/custom_addons/`). For Odoo.sh, add the folder to your repository's branch and push.
2. Make sure that directory is listed in the `addons_path` of your `odoo.conf`.
3. Restart the Odoo service.
4. Log in to Odoo as an administrator and enable **Developer Mode** (Settings → Activate the developer mode).
5. Go to **Apps** → click **Update Apps List** → confirm.
6. Remove the default "Apps" filter, search for **All in One Accessibility Pro**, and click **Install** (or **Activate**).
7. Once installed, the **All in One Accessibility Pro** app appears in the app switcher, and an **Accessibility** section is added to Settings.

Alternatively, install from the command line:

```bash
./odoo-bin -c /path/to/odoo.conf -d YOUR_DATABASE -i odoo_allinoneaccessibilitypro --stop-after-init
```

Then restart the Odoo service.

Package name: `odoo_allinoneaccessibilitypro`

For a detailed walkthrough, see the [**Odoo accessibility app installation guide**](https://www.skynettechnologies.com/blog/odoo-web-accessibility-widget-installation).

Need help? Our support team can assist with the integration if you don't have a development team.

## Configuration

Configure the app from the Odoo admin panel.

**Path:** All in One Accessibility Pro (app switcher) – or Settings → Accessibility → All in One Accessibility Pro → Configure Widget

**Steps:**

1. Log in to the Odoo admin panel.
2. Navigate to All in One Accessibility Pro (app switcher), or Settings → Accessibility → All in One Accessibility Pro → Configure Widget.
3. Configure options (color, icon type, position, size, etc.).
4. Click **Save and Sync Widget** to save your changes.

Your website domain is registered automatically the first time the settings page opens – no license key is required to get started. Changes may take a few seconds to appear on your website; if you don't see them, clear your browser cache or check in a private browsing window.

Advanced settings (accessibility statement link, alt-text editing, team management, analytics) are managed from the [accessibility dashboard](https://ada.skynettechnologies.us/front/login).

## CORS Policy Configuration

To avoid CORS policy issues, ensure the following URLs are allowed on your website. Add them to your CORS configuration or trusted domains list.

| **Domain** | **Description** | **Usage** |
| --- | --- | --- |
| https://\*.skynettechnologies.com | Skynet Technologies (Global Domain) | API access and resources |
| https://\*.skynettechnologies.us | Skynet Technologies (US Domain) | API access and resources |
| https://\*.googleapis.com | Google APIs | Services like Fonts, Translation |
| https://\*.gstatic.com | Fonts APIs | Custom Fonts |
| https://vlibras.gov.br | VLibras – Brazilian Sign Language Service | Sign Language |
| https://ipapi.co | ipapi – IP Geolocation API | Called once during installation to detect an EU location and add the EU-based app script (endpoint: `/json/`) |

**Instructions**

1. Update your server's CORS configuration to include these URLs.
2. Ensure wildcard subdomains (\*) are supported where necessary.
3. Verify functionality by testing requests to these domains.
4. If issues persist, consult the documentation for CORS configuration guidance.

Yes. Each domain and subdomain needs its own license, or you can choose a multisite plan to manage several websites from one dashboard.

**Are any features limited in the free trial?**

No. The 10-day free trial includes all accessibility features.

**Does it support multilingual websites?**

Yes. It supports 190+ languages and automatically detects the visitor's browser language. If your site's default language is, for example, Spanish, the screen reader will read in Spanish.

**Which languages do the screen reader, virtual keyboard, and other features support?**

Screen Reader, Talk & Type, and Live Site Translation support 50+ languages; the Virtual Keyboard supports 40+ languages; Voice Navigation and Dictionary Search support 15+ languages. [See language support details](https://www.skynettechnologies.com/all-in-one-accessibility/languages).

**Can I change the screen reader voice?**

Yes. You can choose from a range of voices by tone, accent, and speech style.

**Does it handle image alt text?**

Yes. AI automatically remediates image alt text, and you can add or edit alt text from the dashboard.

**Can I change the accessibility statement?**

Yes. Set a custom accessibility statement URL from the dashboard under app settings.

**Does it include sign language?**

Yes. It includes Brazilian Sign Language (Libras).

No. The app loads asynchronously and typically adds under 100 ms, with negligible impact on page speed.

**Is there a discount for non-profits or multiple websites?**
